# 0.1.0-alpha

Alpha pre-release of **Build with Manon Mani** (local 1v1 vs AI).

## Play

```bash
git clone https://github.com/gymkathirza/Build_with_MM.git
cd Build_with_MM
npm ci
npm run dev
```

Open http://127.0.0.1:43147 — Skirmish defaults to Vast Mere.

## In this tag

- Map select on Skirmish/March (native link, unique previews, `map=` + `persona=` query)
- Huge default plate Vast Mere (280, pop 100)
- Centered pearl flourish with original two-crest sea + seabird audio
- Clam-with-pearl wealth icon
- Nine rotatable AI personas; east–west hearths (west win ~52% in the hour job)
- Observatory live FPS/input → `/api/obs` → tuner
- GitHub Actions: lint, typecheck, unit tests, short playtest, build
